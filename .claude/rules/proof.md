# Write proof

Always reference the theorem being proved, even if it's the immediately preceding one.
This is to avoid confusion when theorems are added or removed, which can shift numbering.

When referencing multiple statemens, it might be better to write additional corollaries to make cross reference shorter.

Always use the prose style already presented to write new proofs.
The following list gives some style constraints.

- Write "iff" instead of "if and only if".
- Write "suppose that" instead of "assume that".
- Inductions are closed with the statement "This closes the induction".
- One sentence per line.
- Sentences after semicolon are treated as independent sentences, therefore one line per sentence.
